## Hypothèses
- L'admin a besoin d'une **corbeille** pour les commandes supprimées (récupération vs purge définitive) → soft-delete.
- L'état **like/commenté** d'un visiteur doit survivre au refresh (persistance locale + fusion serveur) et être visible sur les cartes produits (highlight).
- L'admin doit pouvoir **retirer les droits admin**, **éditer les mouvements de trésorerie** et **supprimer un panier non confirmé**.
- Le partage produit doit couvrir WhatsApp + Facebook + Gmail + Messenger + TikTok + copie.

## Observations / Diagnostics
1. **Bouton RAFRAÎCHIR admin "cassé"** : cause = lecture *eventual* des blobs Netlify (deux GET successifs → résultats différents). Fix : `consistency: 'strong'` sur `loadUsers`, `loadAccountsFile`, `loadAllOrders`.
2. **Lost update orders** : mutations orders sans verrou cross-instance → commande restaurée disparaissait du blob. Fix : `mutateOrders()` avec `withBlobLock('bm-orders')` en prod / `withLock('orders')` en local, appliqué à create/update/delete/restore/permanent/lead.
3. **Édition trésorerie 404** : `PUT /api/treasury/entries/:id` renvoyait « Mouvement introuvable » juste après un POST (lecture éventuelle de `bm-treasury`). Fix : `loadTreasury()` en strong. Vérifié e2e prod : POST → PUT (label/montant/date/méthode modifiés) → DELETE.
4. **Like perdu au refresh** : `refreshCount` remplaçait l'état local optimiste par la réponse serveur. Fix : fusion `data.liked === true || likedSet.has(id)`.
5. **Cartes produits** : pas de signal visuel de like/commentaire. Fix : classe glow rouge + badges « ❤️ J'aime » / « 💬 Commenté » via `bm_likes_v1` + `bm_commented_v1`.
