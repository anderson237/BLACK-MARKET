# ST-018 — Mentions produit « Neuf / Occasion / Gros » + filtres vitrine — Cycle 1

**Date** : 2026-08-09
**Gate courant** : 4 (Implémentation) → 5 (Tests unitaires / preuve) → Livré à la revue Lab
**Statut** : ✅ Implémenté + testé (tsx) + build OK — aucun commit, aucun déploiement

## Objectif
Ajouter une mention produit optionnelle `mention` (`neuf` | `occasion` | `gros`), sélectionnable
en ajout manuel / import / édition, avec **suggestion auto à l'import**, affichée en vitrine
(carte + fiche) et filtrable sur la page d'accueil (combinable catégorie × mention × recherche),
sans casser les produits anciens sans mention.

## Ce qui a été fait

### 1. Type & constante partagée (`types/index.ts`)
- `Product.mention?: ProductMention` (docstring explicite : champ optionnel, distinct de `condition`).
- Constante partagée `PRODUCT_MENTIONS` (`{value, label}` : neuf/Neuf, occasion/Occasion, gros/Gros)
  + type dérivé `ProductMention`. Réutilisée par le store vitrine, l'éditeur, l'import UI et le test.

### 2. Persistance serveur
- `server/utils/product.ts` : `sanitizeProduct` valide `mention` via une **allowlist stricte**
  (`neuf|occasion|gros`, saisie `trim()`ée). Valeur hors liste ou absente → `undefined`
  (champ non persisté). Backward compat totale : anciens produits sans `mention` inchangés.
- `server/api/admin/import/publish.post.ts` : `body.mention` du draft lu puis passé à
  `sanitizeProduct` (la validation finale reste l'allowlist). Header du body documenté.
- Routes `products.post.ts` / `products.put.ts` : **aucun changement nécessaire** — elles passent
  déjà les produits par `sanitizeProduct`, donc la validation `mention` s'applique automatiquement.

### 3. Suggestion auto à l'import (`server/utils/draftBuilder.ts`)
- Nouvelle fonction exportée `suggestMention({ platform, condition, sourceTitle, sourceDesc })` :
  - `platform === '1688'` → `gros` (nature B2B/wholesale prime) ;
  - texte contenant `二手`/`旧` → `occasion` ; `全新` → `neuf` ;
  - variantes EN `used`/`new` (regex `\b` pour éviter « caused »/« newest ») ;
  - signaux gros `批发`/`wholesale` → `gros` ;
  - sinon → `undefined` (l'admin choisit).
- `buildDraft` retourne désormais `suggestedMention` (champ distinct de `condition`, qui reste
  le texte brut source — jamais modifié).

### 4. Éditeur produit (`components/ProductEditorModal.vue`)
- `draft.mention` initialisé depuis `props.product?.mention` ('' = aucune).
- Select « Mention produit (vitrine) » sous la Catégorie : 4 options (— / Neuf / Occasion / Gros),
  libellés depuis `PRODUCT_MENTIONS`.
- `buildProduct()` : `mention: draft.mention || undefined` → persisté en création ET en édition.

### 5. Import UI (`pages/admin/import.vue`)
- `publishMention` ref pré-remplie par `draft.suggestedMention` (dans `openDraft` ET
  `importFromUrl` — donc le flux recherche ET le flux lien). Toujours modifiable avant publication.
- Select mention dans le modal d'aperçu (section Catégorie), avec badge « ⚡ Suggérée : … »
  quand `draft.suggestedMention` existe.
- `doPublish` : `mention: publishMention.value || undefined` envoyé à `/api/admin/import/publish`.

### 6. Vitrine — carte produit (`components/ProductCard.vue`)
- **Badge compact coloré** en haut-gauche sous le statut stock (colonne `flex` top-gauche, `z-[5]`,
  ne recouvre ni photo ni badges droite VIDEO/-% promo) : Neuf = émeraude, Occasion = ambre,
  Gros = violet. Masqué si pas de mention. Badge glow « Commenté » décalé à `top-16` pour éviter le chevauchement.

### 7. Vitrine — fiche produit (`pages/p/[id].vue`)
- Pastille mention translucide colorée à côté de la catégorie (ém/ambre/violet) via `mentionInfo`.

### 8. Vitrine — filtres (`stores/catalog.ts` + `pages/index.vue`)
- `activeMention = ref('Tous')` + `mentions` computed (`['Tous','Neuf','Occasion','Gros']`) +
  `setMention()` qui appelle `resetAndSlice()`.
- `filtered()` combine **catégorie × mention × recherche** (mention filtrée par valeur normalisée
  via `PRODUCT_MENTIONS` ; produits sans mention inclus tant qu'aucune mention n'est active).
- `pages/index.vue` : ligne d'onglets mentions sous les onglets catégorie (pastilles violettes,
  actif = violet plein, style plus compact) + état vide adapté :
  « AUCUN DROP DANS « X » EN « Y » » / « AUCUN DROP EN « Y » ».

## Limites / points d'attention (revue Lab)
- **Suggestion auto conservative** : seuls des indices nets (1688, 二手/旧/全新, used/new,
  批发/wholesale) pré-remplissent la mention. Un produit goofish avec `itemStatusStr` neutre
  (« 在线 ») ne reçoit **aucune** suggestion → l'admin choisit (conforme spec « sinon pas de
  suggestion »). Affinages éventuels (taobao second-hand, douyin) en cycle 2.
- **`condition` n'est PAS persisté** sur le produit publié (champ de draft/aperçu uniquement,
  comportement inchangé). La séparation `condition`/`mention` est vérifiée au niveau du
  `suggestMention` (test scénario 5).
- **UI** : la pastille mention sur la carte est volontairement discrète (8px). Si le Lab veut
  plus de présence, ajuster `text-[8px]`/`px-2` dans `ProductCard.vue`.
- **Aucun retrait** des messages d'état vide existants — l'ajout mention est cumulatif.
