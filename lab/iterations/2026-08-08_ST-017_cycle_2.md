## Endpoints JustOneAPI confirmés (docs + appels réels 2026-08-08)

### TikTok Shop
- **Search** : `GET /api/tiktok-shop/search-products/v1` — params : `token`, `keyword`, `region` (US|GB|FR|SG|MY|PH|TH|VN|ID, défaut US), `offset`, `pageToken`.
- **Détail** : `GET /api/tiktok-shop/get-product-detail/v1` — params : `token`, `productId`, `region` (défaut US).
- **Réponse search (appel réel, région US, mot-clé sneakers)** : enveloppe `{code, data:{...}, message, recordTime, requestId}` avec **double imbrication** : les produits sont dans `data.data.products[]` :
  - `product_id`, `title`, `image.url_list[]`, `product_price_info` (`sale_price_decimal` "5.98", `currency_name` USD, `currency_symbol` $, `promotion_deduction_details`), `rate_info` (`score`, `review_count`), `sold_info` (`sold_count`), `seller_info` (`seller_id`, `shop_name`, `shop_logo`), `seo_url.canonical_url` (URL PDP), `product_marketing_info` (labels : Free shipping, Limited time deal…), `sku_info[]` (variantes × prix).
  - Pagination : `data.load_more_params` (`offset`, `page_token`).
  - ⚠️ **301 COLLECT FAILED intermittent** : premier essai `iphone` région FR → 301 ; nouvel essai `sneakers` région US → OK. Comportement côté fournisseur : réessayer.
- **Régions FR disponibles** : la recherche `region=FR` est supportée (tentative initiale, 301 = collect failed, pas 400).

### Amazon
- **Search** : `GET /api/amazon/search-products/v1` — params : `token`, `keyword` (mot-clé OU ASIN), `country` (US|AU|BR|CA|CN|FR|DE|IN|IT|MX|NL|SG|ES|TR|AE|GB|JP|SA|PL|SE|BE|EG|ZA|IE, défaut US), `sortBy` (RELEVANCE|LOWEST_PRICE|HIGHEST_PRICE|REVIEWS|NEWEST|BEST_SELLERS, défaut RELEVANCE), `productCondition` (ALL|NEW|USED|RENEWED|COLLECTIBLE), `isPrime` (bool), `dealsAndDiscounts` (NONE|ALL_DISCOUNTS|TODAYS_DEALS), `page` (défaut 1).
- **Réponse search (appel réel, country FR, mot-clé iphone)** : `data.products[]` :
  - `asin`, `product_title`, `product_price` (string "949,00 €"), `product_original_price` (null si pas de promo), `currency` (EUR), `product_star_rating` "4.5", `product_num_ratings`, `product_url` (https://www.amazon.fr/dp/ASIN), `product_photo`, `product_num_offers`, `product_minimum_offer_price`, `is_best_seller`, `is_amazon_choice`, `is_prime`, `climate_pledge_friendly`, `sales_volume` ("Plus de 500 achetés au cours du mois dernier"), `delivery`, `has_variations`.
  - Méta : `data.total_products`, `data.country`, `data.domain` (www.amazon.fr).
- **Autres endpoints Amazon (docs)** : Product Details V1, Product Top Reviews V1, Best Sellers V1, Products By Category V1.

### Douyin E-commerce
- **Search** : `GET /api/douyin-ec/search-item-list/v1` — params : `token`, `keyword`, `page`, `searchId` (utiliser le `search_id` retourné pour les pages suivantes).
- **Réponse search (appel réel, mot-clé iphone)** : `data.summary_promotions[]` :
  - `product_id`, `promotion_id`, `base_model` :
    - `product_info` : `name`, `main_img.url_list[]` (image produit), `white_img`, `detail_url` (https://haohuo.jinritemai.com/…id=…), `category` (first/second/third `category_name`), `product_status`, `month_sale.origin` (ventes du mois, ex. 39727), `good_ratio.origin` (note %, ex. 92.8), `month_sale_text`, `sale_axis[]` (historique 30 jours : `{x:"20260710", y:1409}` — parfait pour trending).
    - `marketing_info.price_desc` : **`price.origin` en centimes ¥** (1590 = 15,90 ¥), `regular_price.origin` (1790), `price_text` (libellé promo).
    - `promotion_info` : `promotion_status`, `cos_info`.
    - `shop_info` : `shop_id`, `shop_name`, `shop_logo`, `shop_score_info`.
  - Méta : `data.has_more`, `data.total` (500), `data.extra.search_id` (pagination), `data.log_id`.
- **Autres endpoints Douyin (docs)** : Item Details V2, Product SKU Info V1, Item Comments V1, Shop Product List V1.

### Taobao / Tmall (ajout demandé)
- **Search** : `GET /api/taobao/search-item-list/v1` — params : `token`, `keyword`, `sort` (`_sale`=ventes|`_bid`=prix décroissant|`bid`=prix croissant|`_coefp`=général), `tmall` (bool, filtre Tmall uniquement), `startPrice`, `endPrice` (bornes ¥ inclusives), `page`.
- **Réponse search (appel réel, mot-clé iphone)** : `data.model.itemList[]` :
  - `itemId`, `itemName`, `itemSubName`, `discntPriceYuan` (float ¥, ex. 8999.0), `discntRate`, `discntType`, `priceYuanDouble`, `priceZKFen`, `priceZKYuanDouble`, `picUrlFull` (URL complète), `picUrlList[]`, `itemLoc` (ville), `orderPayUV` (ventes "1000+"), `shopId`, `shopName`, `sellerLevel`, `sellerGoodrat`, `frontStock`, `spuId`, `commentCount`, `fahuoDsr`/`fuwuDsr`/`miaoshuDsr` (DSR vendeur), `tmcTagList`.
  - Méta : `data.model.page`, `data.model.success`, `data.code` ("SUCCESS").
- **Détails** : `GET /api/taobao/get-item-detail/v1|v3|v4|v5|v6|v9` (itemId) ; **Shop list** : `GET /api/taobao/get-shop-item-list/v1` (userId, sort `_sale`|`_default`) / v2 / v3 (userId+shopId, sort `coefp`|`hotsell`|`oldstarts`|`bid`|`_bid`) / v4.
- **Structure très proche de 1688** (`data.model.itemList[]`) → le flattener 1688 est réutilisable pour Taobao.

## Codes d'erreur communs
`0` succès · `100` token invalide · `301` collect failed (réessayer) · `302` TOO FAST (rate limit — espacer) · `303` quota quotidien · `400` paramètres invalides · `500` erreur interne · `600` permission · `601` solde insuffisant · `602` budget dépassé.

## Observations d'appels réels
- Amazon : 34,8 Ko (48 produits), country FR, devises EUR — structure plate et propre.
- Douyin : 154 Ko (30 promotions), prix en centimes ¥ (÷100), sale_axis = historique 30 j pour détecter les hausses.
- Taobao : 13,5 Ko (10 items), prix en ¥ float, DSR vendeur, ventes orderPayUV.
- TikTok : 112 Ko (5 produits) — nécessite parfois 2 essais (301), et `data.data.products` (double imbrication).
